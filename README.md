# Ariane

> Ariadne's thread through your projects.

**Ariane** is an AI-assisted, file-based, hierarchical project management method.

It defines a common **process** shared by everyone who uses it, while each user keeps their own **content** — plans, stories, tasks, decisions — centralized in a single personal repository, materialized wherever they work.

## Status

🚧 **Work in progress** — the method is being bootstrapped. See [PLAN.md](./PLAN.md) for the design plan and roadmap.

## Install

```sh
brew install slashome/tap/ariane
```

From a checkout, `make install` builds the front and installs the binary into `~/.cargo/bin`; `make` lists every target. `make release VERSION=x.y.z` tags a release, which the CI builds and publishes to the tap.
